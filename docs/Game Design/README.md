# Realmbreaker

Realmbreaker is a Roblox cultivation MMORPG currently in development.

This repository contains all game design documentation.

These documents are considered the source of truth for every future system.

Whenever a feature is changed, these documents should be updated instead of creating conflicting information.

Priority:

1. Gameplay
2. Player Experience
3. Long-term Progression
4. Scalability
5. Maintainability
