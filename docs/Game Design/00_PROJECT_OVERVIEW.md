# Project Overview

## Game Name

Realmbreaker

---

## Genre

Cultivation MMORPG

Anime Action RPG

Open World Multiplayer

PvP + PvE

---

## Vision

Create the highest quality cultivation MMORPG on Roblox.

The game should emphasize meaningful progression instead of endless grinding.

Every realm should unlock new gameplay.

The player should always have meaningful goals.

---

## Core Philosophy

Cultivation is not the game.

Cultivation unlocks the game.

---

• Excellent Combat

• Excellent UI

• Exploration

• Player Competition

• Social Systems

• Long-Term Progression

• Replayability
